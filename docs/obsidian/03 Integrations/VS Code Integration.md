# VS Code Integration

Forge Studio detects the official `code` command-line interface. Opening a project or changed file from the UI is not implemented yet. The planned command path passes explicit project and file arguments to the CLI; it will not attempt arbitrary UI control. Git & Changes already shows paths and diffs for manual inspection.
